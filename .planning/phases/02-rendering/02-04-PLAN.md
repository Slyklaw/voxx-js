<objective>
Implement vertex pooling to batch multiple chunks into fewer draw calls, reducing CPU overhead.

Purpose: Naive rendering creates separate vertex buffers for each chunk, causing many small draw calls that saturate the CPU. Vertex pooling combines geometry into shared buffers, enabling single draw calls for multiple chunks and dramatically reducing CPU-GPU communication overhead.

Output: VertexPool class manages shared vertex/index buffers. Renderer adds chunk geometry to pool and draws all chunks in one batched call per material.
</objective>
