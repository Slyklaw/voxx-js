  <files>voxx-js/src/gl/shaders.js</files>
  <action>
Create shaders.js module that:
- Exports compileShader(gl, type, source) function: creates shader, compiles, checks errors with getShaderInfoLog, returns shader or throws
- Exports createProgram(gl, vertexSource, fragmentSource) function: compiles both shaders, links program, checks errors with getProgramInfoLog, returns program
- Exports getUniformLocations(gl, program, names) helper: returns object with uniform locations
- Exports getAttribLocations(gl, program, names) helper: returns object with attribute locations
- Provides sample vertex shader: takes position (vec3), outputs gl_Position with simple MVP transform placeholder
- Provides sample fragment shader: outputs solid color (vec4)

Key pattern: Check gl.getShaderParameter(shader, gl.COMPILE_STATUS) after compilation - critical pitfall from research.
