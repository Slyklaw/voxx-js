## v1.1 Milestone Summary

**Key Decisions:**
- Keep Three.js BoxGeometry for block outline (simpler than custom WebGL2 shader)
- Created persistent outline mesh with visibility toggle (eliminated per-frame allocation)
- Used continue-skip pattern for chunk rebuilds (allows partial progress across frames)
- `MAX_REBUILDS_PER_FRAME` set to 2 (balance responsiveness vs performance)

**Technical Patterns:**
- Frame-budgeted rebuild limiting
- Counter-based throttle with continue-skip
- Keyboard selection with pointer lock guard

**Issues Resolved:**
- Eliminated GC pressure from per-frame geometry allocation in block outline
- Prevented frame drops during rapid block editing with throttling
