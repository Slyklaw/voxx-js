  <action>
    In the fragment shader of `voxx-js/src/shaders/voxel.js`, modify the `ShadowCalculation` function (lines 91-114).

    Current implementation uses a 3x3 PCF kernel:
    ```glsl
    float shadow = 0.0;
    vec2 texelSize = 1.0 / vec2(4096.0);
    for (int x = -1; x <= 1; ++x) {
      for (int y = -1; y <= 1; ++y) {
        shadow += texture(uShadowMap, vec3(projCoords.xy + vec2(x, y) * texelSize, projCoords.z - bias));
      }
    }
    return shadow / 9.0;
    ```

    Replace with a single hard shadow lookup (no PCF loop):
    ```glsl
    // Hard shadow — single texel lookup, no filtering
    float shadow = texture(uShadowMap, vec3(projCoords.xy, projCoords.z - bias));
    return shadow;
    ```

    Keep everything else in the function intact:
    - Perspective divide (line 93)
    - [0,1] range transform (line 95)
    - Out-of-bounds checks returning 1.0 (lines 98-99)
    - Bias calculation (line 102)

    Do NOT modify any other code in the file — no uniforms, no vertex shader, no imports.
