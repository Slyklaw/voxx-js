  <name>Add chunk position as instance attribute to voxel shader</name>
  <files>voxx-js/src/shaders/voxel.js</files>
  <action>
    Modify the voxel vertex shader to accept chunk position as an instance attribute:

    1. Add `layout(location = 3) in vec3 aChunkOffset;` after existing attributes
    2. Modify vertex transformation to: `vec3 worldPos = aPosition + aChunkOffset;`
    3. Use `worldPos` instead of position for gl_Position calculation

    The shader currently receives local vertex positions. With instancing, we add chunk world offset to transform each instance (chunk) to its correct position.
  </action>

    <manual>Visual: All chunks should render in correct world positions. Check that chunks at different coordinates (e.g., 1,0 and 2,0) appear in correct locations.</manual>
  </verify>

</task>

<task type="auto">
  <name>Setup instanced rendering in chunk manager</name>
  <files>voxx-js/src/chunk/chunkManager.js</files>
  <action>
    Modify chunk manager to prepare instance data for rendering:

    1. Create Float32Array buffer to store chunk world positions (x, z) or (x, y, z) for all loaded chunks
    2. Each chunk's offset = chunkX * CHUNK_SIZE, 0, chunkZ * CHUNK_SIZE
    3. Update buffer when chunks load/unload
    4. Use vertexAttribDivisor(3, 1) to advance chunk offset once per instance

    Reference: WebGL2 drawElementsInstanced requires instance attributes to have divisor set to 1.
  </action>
