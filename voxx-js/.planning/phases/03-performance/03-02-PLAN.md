Purpose: Currently getVisibleChunks() iterates ALL loaded chunks. With grid-based approach, only chunks within render distance are checked - O(renderDistance^2) vs O(totalChunks).

Output: Modified world.js with spatial index and camera-based dirty flag
</objective>
