<objective>
Fix the diagonal movement speed bug where moving diagonally (e.g., forward + left) is faster than moving straight due to lack of velocity vector normalization.

Purpose: In the current implementation, pressing forward sets velocity.z = -moveSpeed and pressing left adds velocity.x = moveSpeed. The resulting diagonal velocity magnitude is sqrt(moveSpeed² + moveSpeed²) = moveSpeed * sqrt(2) ≈ 1.41x faster than intended. This gives players an unfair speed advantage when moving diagonally.

Output: Player movement is consistent regardless of direction. Diagonal movement has the same speed as cardinal movement through vector normalization.
</objective>

<task type="auto" name="Task 1: Fix diagonal movement normalization">
<files>src/player/player.js</files>
<action>
Fix handleMovement() to normalize diagonal movement:

Current bug (lines 163-186):
- Forward sets velocity.x and velocity.z independently
- Left/right adds to velocity.x and velocity.z
- Result: diagonal = sqrt(2) * moveSpeed

Fix approach:
1. Calculate intended movement direction as a 2D vector (moveX, moveZ)
2. If any movement key is pressed, normalize the vector
3. Scale by moveSpeed

Modified handleMovement():
```javascript
handleMovement(deltaTime) {
    const moveSpeed = this.movement.sneak ? this.walkSpeed / 2 : this.walkSpeed;
    
    // Calculate raw movement direction
    let moveX = 0;
    let moveZ = 0;
    
    // Forward/backward (along -z/+z axis)
    if (this.movement.forward && !this.movement.backward) {
        moveZ = -1;
    } else if (this.movement.backward && !this.movement.forward) {
        moveZ = 1;
    }
    
    // Strafing left/right (along -x/+x axis)
    if (this.movement.left && !this.movement.right) {
        moveX = -1;
    } else if (this.movement.right && !this.movement.left) {
        moveX = 1;
    }
    
    // Normalize diagonal movement
    const magnitude = Math.sqrt(moveX * moveX + moveZ * moveZ);
    if (magnitude > 0) {
        // Normalize and scale by moveSpeed
        this.velocity.x = (moveX / magnitude) * moveSpeed;
        this.velocity.z = (moveZ / magnitude) * moveSpeed;
    } else {
        this.velocity.x = 0;
        this.velocity.z = 0;
    }
    
    // Apply rotation to movement direction
    const cos = Math.cos(this.rotation.yaw);
    const sin = Math.sin(this.rotation.yaw);
    const finalX = this.velocity.x * cos - this.velocity.z * sin;
    const finalZ = this.velocity.x * sin + this.velocity.z * cos;
    this.velocity.x = finalX;
    this.velocity.z = finalZ;
}
```

Note: The current implementation applies yaw rotation in the velocity calculation. We need to preserve this behavior while normalizing.

import { jest } from '@jest/globals';
import { Player } from './player.js';

describe('Player movement normalization', () => {
    let player;
    
    beforeEach(() => {
        // Mock document for Player constructor
        global.document = {
            getElementById: () => ({ requestPointerLock: jest.fn() }),
            addEventListener: jest.fn(),
            removeEventListener: jest.fn(),
            pointerLockElement: null,
        };
        player = new Player();

    test('forward movement has correct speed', () => {
        player.movement.forward = true;
        player.update(0.1);
        const speed = Math.sqrt(player.velocity.x ** 2 + player.velocity.z ** 2);
        expect(speed).toBeCloseTo(player.walkSpeed, 5);
    });
    
    test('diagonal movement equals straight movement speed', () => {
        player.movement.forward = true;
        player.movement.left = true;
        player.update(0.1);
        const diagonalSpeed = Math.sqrt(player.velocity.x ** 2 + player.velocity.z ** 2);
        
        // Reset and test straight
        player.velocity = { x: 0, y: 0, z: 0 };
        player.movement.left = false;
        player.update(0.1);
        const straightSpeed = Math.sqrt(player.velocity.x ** 2 + player.velocity.z ** 2);
        
        expect(diagonalSpeed).toBeCloseTo(straightSpeed, 5);
    });
    
    test('sneak halves speed', () => {
        player.movement.forward = true;
        player.movement.sneak = true;
        player.update(0.1);
        const speed = Math.sqrt(player.velocity.x ** 2 + player.velocity.z ** 2);
        expect(speed).toBeCloseTo(player.walkSpeed / 2, 5);
    });
    
    test('no movement when no keys pressed', () => {
        player.update(0.1);
        expect(player.velocity.x).toBe(0);
        expect(player.velocity.z).toBe(0);
    });
});
