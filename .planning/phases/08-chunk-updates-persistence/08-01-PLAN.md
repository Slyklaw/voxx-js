<objective>
Verify that block edits are visually updated immediately and persist until page reload, and optimize chunk mesh rebuilds to prevent frame drops.
</objective>

<context>
@.planning/STATE.md
@.planning/ROADMAP.md
@.planning/REQUIREMENTS.md

Existing implementation:
- destroyBlock() and placeBlock() already call chunk.updateMesh(true) with forceUpdate flag
- chunk.setVoxel() updates voxel data and sets needsUpdate flag
- updateChunks() loop detects needsUpdate and recreates WebGL mesh via syncChunkToWebGL
- Block data stored in chunk.voxels (Uint8Array) in-memory only
- No persistence to localStorage (deferred to v2)

Potential performance issue:
- updateChunks() rebuilds all dirty chunks each frame, which could cause frame spikes when many chunks need update simultaneously.
</context>
