```javascript
const dominantBiome = blendFactor < 0.5 ? primaryBiome : secondaryBiome;
```

This causes harsh edges at biome transitions. Fix by blending block types based on biome contributions:

1. After calculating blended height, blend the block types at transition zones
2. When blendFactor is between 0.3 and 0.7 (transition zone), mix block types proportionally
3. Use a smooth interpolation for grass/dirt layers at boundaries
4. The dominant biome determines deep block types (stone), but surface blocks blend gradually

The key insight: at biome transitions, the surface should smoothly blend between biomes' block types, not switch abruptly.
