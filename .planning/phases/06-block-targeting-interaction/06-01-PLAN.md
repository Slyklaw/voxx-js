    Ensure raycastBlock() correctly:

    - localX = Math.floor(x - chunkX * CHUNK_WIDTH)

<task type="auto">
  <name>Task 2: Verify selection outline renders at targeted block position</name>
  <files>voxx-js/renderer.js</files>
  <action>
    Verify updateBlockOutline() method:
    1. Receives targetedBlock from render() call chain
    2. Creates/updates outlineMesh as BoxGeometry(1.02, 1.02, 1.02)
    3. Uses MeshBasicMaterial with color 0xff00ff (purple), wireframe: true
    4. Positions mesh at (worldX + 0.5, worldY + 0.5, worldZ + 0.5) for block centering
    5. Removes outline when targetedBlock is null or hit=false
    
    The 1.02 size makes outline slightly larger than 1x1 block for visibility.
    Outline is added to scene and rendered with each frame.
  </action>
  <verify>

<task type="auto">
  <name>Task 3: Clear outline when no block targeted</name>
  <files>voxx-js/renderer.js</files>
  <action>
    Ensure updateBlockOutline() properly disposes old outline mesh when:
    1. targetedBlock is null
    2. targetedBlock.hit is false
    
    Disposal steps:
    - scene.remove(outlineMesh)
    - outlineMesh.geometry.dispose()
    - outlineMesh.material.dispose()
