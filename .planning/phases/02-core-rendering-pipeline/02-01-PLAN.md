  <action>
Create voxx-js/src/gl/buffers.js with VBO and VAO management:

1. createVBO(gl, data, usage) - Create vertex buffer with data (Float32Array), usage = gl.STATIC_DRAW for chunk geometry
2. createVAO(gl) - Create vertex array object
3. setupVAO(gl, vao, vbo, attribs) - Configure vertex attributes: position (3 floats), color (3 floats), normal (3 floats)
4. bindChunk(gl, vao) - Bind VAO for drawing (single call)
5. unbindChunk(gl) - Unbind VAO
6. deleteChunk(gl, vao, vbos) - Clean up GPU resources on chunk unload

Use interleaved VBO format: [posX,posY,posZ, colR,colG,colB, normX,normY,normZ] = 9 floats per vertex = 36 bytes

Reference Phase 1 context.js for gl reference and shaders.js for error handling patterns.

<task type="auto">
  <name>Task 2: Create voxel shaders with vertex colors</name>
  <files>voxx-js/src/shaders/voxel.js</files>
  <action>
Create voxx-js/src/shaders/voxel.js with GLSL ES 3.00 shaders:

Vertex shader:
- Inputs: aPosition (vec3), aColor (vec3), aNormal (vec3)
- Uniforms: uModelViewProjection (mat4), uModelMatrix (mat4)
- Outputs: vColor (vec3), vNormal (vec3) for lighting
- Compute: gl_Position = uModelViewProjection * vec4(aPosition, 1.0)

Fragment shader:
- Inputs: vColor (vec3), vNormal (vec3)
- Uniforms: uLightDirection (vec3), uAmbient (float), uDiffuse (float)
- Output: fragColor (vec4)
- Compute: Simple directional lighting - ambient + diffuse * max(dot(normal, light), 0.0)
- Default: uLightDirection = normalize(vec3(0.5, 1.0, 0.3)), uAmbient = 0.4, uDiffuse = 0.6

Export: createVoxelProgram(gl), getVoxelUniforms(gl, program), getVoxelAttribs(gl, program)
Use shaders.js createProgram utility from Phase 1.
  </action>
