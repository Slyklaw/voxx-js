Create voxx-js/src/gl/ubo.js for shared globals:

1. createUBO(gl, size) - Create uniform buffer with given size
2. CameraUBO layout (64 bytes): mat4 view (16 floats), mat4 projection (16 floats) = 32 floats total
3. GlobalUBO layout (16 bytes): vec3 lightDirection, float timeOfDay (0-1), vec3 ambientColor

- updateGlobalUBO(gl, ubo, lightDir, timeOfDay, ambient) - Upload lighting globals
- bindUBO(gl, ubo, bindingPoint) - Bind to uniform binding point 0 for camera, 1 for globals
- deleteUBO(gl, ubo) - Clean up

UBO indices: CAMERA_UBO = 0, GLOBAL_UBO = 1

The voxel shader from Plan 01 should be updated to use UBO instead of individual uniforms.

<task type="auto">
  <name>Task 2: Create sky dome shader with day/night cycle</name>
  <files>voxx-js/src/shaders/sky.js</files>
  <action>
Create voxx-js/src/shaders/sky.js for sky dome rendering:

Vertex shader:
- Input: aPosition (vec3) - unit cube or sphere vertices
- Uniforms: uModelMatrix (mat4), uViewMatrix (mat4), uProjectionMatrix (mat4)
- Output: vPosition (vec3) - world position for gradient
- Remove translation from view matrix (sky stays at infinity)

Fragment shader:
- Uniforms: uTimeOfDay (float 0-1), uDayTopColor (vec3), uDayBottomColor (vec3), uNightTopColor (vec3), uNightBottomColor (vec3)
- Mix colors based on uTimeOfDay: lerp from night to day colors
- Vertical gradient: mix top/bottom based on y component of vPosition
- Day colors: top #87CEEB (sky blue), bottom #FFFFFF (white horizon)
- Night colors: top #0B1026 (dark blue), bottom #1B2745 (navy)
- No depth test for sky (always behind everything) - disable depth write

Export: createSkyProgram(gl), renderSky(gl, program, timeOfDay)
  </action>
  <verify>
    <automated>Check file exists and exports createSkyProgram, renderSky</automated>
    <manual>Verify shader uses mix() for both time-of-day and vertical gradient</manual>
  </verify>
  <done>
    - Sky renders as gradient from horizon to zenith
    - Colors transition based on timeOfDay uniform
    - Day colors: sky blue to white
    - Night colors: dark blue to navy
  </done>
</task>

<action>
Create voxx-js/src/shaders/selection.js for wireframe selection:

Vertex shader:
- Input: aPosition (vec3)
- Uniforms: uModelViewProjection (mat4), uBlockPosition (vec3), uBlockSize (float = 1.0)
- Expand aPosition by uBlockSize around uBlockPosition to create outline box
- Alternative: Use GL_LINES instead of GL_TRIANGLES for wireframe

Fragment shader:
- Uniforms: uSelectionColor (vec3) - default #FF00FF (magenta)
- Output: solid color (ignore lighting)
- Set gl.POLYGON_OFFSET to avoid z-fighting with block faces

Two rendering approaches (pick one):
1. Wireframe mode: gl.drawElements(gl.LINES, ...) with line indices
2. Barycentric: Render filled with barycentric coords, discard in shader for edges

Export: createSelectionProgram(gl), renderSelection(gl, program, blockPos)
