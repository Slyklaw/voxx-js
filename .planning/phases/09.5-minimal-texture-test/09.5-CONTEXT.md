# Phase 9.5 Context: Minimal Texture Test

## Root Cause Found

The texture pipeline was never actually implemented. The previous phases (9-10) documented code that doesn't exist:
- Shaders have NO texture sampling
- Vertex format has NO UV coordinates
- Renderer has NO texture loading
- No `sampler2D` uniform exists anywhere

The "verification" was checking code comments, not actual functionality.

## What Actually Exists
- `blocks.js` has `atlasPos` definitions ✓
- `getBlockAtlasPositions()` helper exists ✓
- Chunk mesh generation produces positions, colors, normals ✓

## What's Missing (Entire Pipeline)
1. Vertex format lacks UV (currently 9 floats, needs 11)
2. Vertex shader has no `aUV` input or `vUV` output
3. Fragment shader has no `sampler2D` or `texture2D()` call
4. No texture loading code in renderer
5. No texture binding before draw calls

## Minimal Test Goal
Get ONE block face showing a texture from the atlas. Nothing else. Then iterate.
