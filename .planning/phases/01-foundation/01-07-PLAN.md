Add a test to verify that world generation with the same seed produces identical voxel data.

The test should:
1. Create a new World instance (default seed is WORLD_SEED_DEFAULT = 42)
2. Generate a chunk at coordinates (0, 0, 0) and capture its voxel data
3. Create another World instance with the same seed (or reuse existing world)
4. Generate the same chunk again (or compare with previously generated chunk)
5. Assert that the voxel arrays are identical

Note: The World.generateChunk method returns a Chunk object. To compare voxel data, we need to extract the internal voxel array. The Chunk class has a `getVoxel(x, y, z)` method, but we need to compare all voxels. Instead, we can compare the chunk's internal `voxels` property (if accessible) or iterate through all coordinates.

Since Chunk's voxels array is private, we can compare by sampling a set of coordinates or by checking that the chunk's data is identical. However, the verification requirement is to ensure determinism, not necessarily deep equality of internal arrays.

Better approach: Generate chunk, store reference, then generate again and compare that the chunk's voxel data matches. Since generateChunk returns the same chunk if already generated (cached), we need to create two separate World instances with same seed.

Implementation:

```javascript
test('world generation is deterministic with same seed', () => {
  const seed = 42; // WORLD_SEED_DEFAULT
  const world1 = new World();
  const world2 = new World(); // same default seed
  
  // Generate chunk in first world
  const chunk1 = world1.generateChunk(0, 0, 0);
  expect(chunk1).toBeDefined();
  
  // Generate same chunk in second world
  const chunk2 = world2.generateChunk(0, 0, 0);
  expect(chunk2).toBeDefined();
  
  // Compare voxel data at multiple sample points
  const samplePoints = [
    [0, 0, 0],
    [16, 16, 16],
    [31, 31, 31],
    [5, 10, 20],
    [0, 31, 0],
  ];
  
  for (const [x, y, z] of samplePoints) {
    const voxel1 = chunk1.getVoxel(x, y, z);
    const voxel2 = chunk2.getVoxel(x, y, z);
    expect(voxel2).toEqual(voxel1);
  }
  
  // Also verify that chunk's height data matches (if available)
  // For simplex noise, height should be identical
  // We can sample getHeightAt if World exposes it, but generateChunk already uses seeded noise.
});
```

Also add a test that changing the seed produces different terrain:

```javascript
test('world generation differs with different seeds', () => {
  const world1 = new World();
  const world2 = new World();
  world2.worldSeed = 12345; // different seed
  
  const chunk1 = world1.generateChunk(0, 0, 0);
  const chunk2 = world2.generateChunk(0, 0, 0);
  
  // At least one sample point should differ
  let differs = false;
  for (let x = 0; x < 32 && !differs; x += 5) {
    for (let y = 0; y < 32 && !differs; y += 5) {
      for (let z = 0; z < 32 && !differs; z += 5) {
        const voxel1 = chunk1.getVoxel(x, y, z);
        const voxel2 = chunk2.getVoxel(x, y, z);
        if (voxel1 !== voxel2) {
          differs = true;
        }
      }
    }
  }
  expect(differs).toBe(true);
});
```
