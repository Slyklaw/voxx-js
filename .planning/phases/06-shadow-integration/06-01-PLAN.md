This creates a 128×128 unit frustum — too small for render distance 8 (8 chunks × 32 units = 256 units radius, 512 units diameter).

Change the orthographic size to cover the full render distance:

<task type="auto">
  <name>Task 2: Add frustum culling to shadow pass</name>
  <files>voxx-js/src/gl/render.js</files>
  <action>
In `renderVoxelsToGBuffer()` (lines 1044-1081), the shadow pass iterates ALL chunks without checking if they're within the shadow camera's view frustum. This wastes GPU time rendering chunks that won't contribute to the shadow map.

Add frustum culling to the shadow pass loop (around line 1066):

1. Before the shadow pass loop, compute the shadow camera's frustum bounds. The shadow camera is positioned at `lightPos` (from createLightSpaceMatrix) looking at `center` (camera position). The orthographic frustum extends `±size` in X and Z, and `near` to `far` in depth.

2. For each chunk, check if its bounding box intersects the shadow frustum. Since chunks are axis-aligned and the shadow camera uses an orthographic projection aligned with the light direction, a simple bounds check is sufficient:
   - Compute chunk center world position: `chunkX * CHUNK_SIZE + CHUNK_SIZE/2, 0, chunkZ * CHUNK_SIZE + CHUNK_SIZE/2`
   - Transform chunk center by the lightSpaceMatrix to get light-space coordinates
   - If the light-space X, Y, or Z is outside the orthographic bounds (±size for X/Y, near-far for Z), skip the chunk

3. Add a helper function `isChunkInShadowFrustum(chunk, lightSpaceMatrix, frustumSize, near, far)` before the renderVoxelsToGBuffer function.

4. In the shadow pass loop, wrap the draw call:
```js
for (let i = 0; i < chunks.length; i++) {
  const chunkMesh = chunks[i];
  if (!chunkMesh || !chunkMesh.vao || !chunkMesh.ibo || !chunkMesh.indexCount) continue;
  
  // Frustum culling: skip chunks outside shadow camera view
  if (currentLightSpaceMatrix && !isChunkInShadowFrustum(chunkMesh, currentLightSpaceMatrix, size, 1.0, farPlane)) continue;
  
  bindChunk(gl, chunkMesh.vao);
  // ... rest of draw call
}
```

Note: The `chunks` array contains raw mesh objects, not Chunk objects with x/z properties. You'll need to pass chunk positions separately or extract them from the model matrix. Since the shadow pass receives `chunks` (which are `visibleChunks` from main.js — actual Chunk objects with `_webglMesh`), use `chunkMesh.chunkX` and `chunkMesh.chunkZ` properties (Chunk class has `.x` and `.z`).

Import CHUNK_SIZE from chunkManager at the top of render.js if not already present.

Do NOT change the shadow map resolution. Do NOT add PCF filtering.
