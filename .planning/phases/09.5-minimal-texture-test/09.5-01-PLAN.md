# Phase 9.5: Minimal Texture Test Plan

**Goal:** One block face shows texture from atlas (visual confirmation)

## Tasks

### Task 1: Extend Vertex Format
**File:** `voxx-js/src/gl/buffers.js`
- Change `VERTEX_SIZE` from 9 to 11 floats
- Add `UV_OFFSET: 32` to `VERTEX_FORMAT`
- Update `createChunkMeshFromData` to accept uvs parameter
- Add UV attribute pointer setup (location 3)

### Task 2: Add UV to Vertex Shader
**File:** `voxx-js/src/shaders/voxel.js`
- Add `in vec2 aUV;` to vertex shader
- Add `out vec2 vUV;` to vertex shader
- Pass through: `vUV = aUV;`
- Update `getVoxelAttribs` to include `'aUV'`

### Task 3: Add Texture Sampling to Fragment Shader
**File:** `voxx-js/src/shaders/voxel.js`
- Add `in vec2 vUV;` input
- Add `uniform sampler2D uTextureAtlas;`
- Replace `vec3 finalColor = vColor * (ambient + diffuse);` with texture sampling
- Use: `vec4 texColor = texture(uTextureAtlas, vUV);`
- Mix: `vec3 finalColor = texColor.rgb * (ambient + diffuse);`
- Update `getVoxelUniforms` to include `'uTextureAtlas'`

### Task 4: Generate UV Coordinates in Chunk Mesh
**File:** `voxx-js/chunk.js`
- Add UV array generation in `generateMeshData()`
- For each face vertex, calculate UV based on block type and atlas position
- Return uvs array alongside positions, colors, normals

### Task 5: Load Texture Atlas
**File:** `voxx-js/src/gl/render.js`
- Create `loadTextureAtlas(gl, url)` function
- Load `textures-atlas.png`
- Create WebGL texture, set parameters (NEAREST filtering)
- Bind texture before each chunk draw call

### Task 6: Wire It All Together
**File:** `voxx-js/src/main.js`
- Call `loadTextureAtlas()` after renderer init
- Pass texture to chunk rendering

## Test Procedure
1. Load game in browser
2. Open console - should see no errors
3. Visual: Blocks should show SOME texture (may be wrong texture, but not flat gray)
4. If texture shows → proceed to debug atlas positions
5. If still gray → debug which step failed

## Success Criteria
1. Blocks are no longer flat gray
2. At least one texture visible from atlas
3. Console shows texture loading success message
