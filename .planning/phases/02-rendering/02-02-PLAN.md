<objective>
Implement frustum culling to skip rendering chunks outside the camera's view frustum.

Purpose: Rendering chunks the camera can't see wastes GPU time. Frustum culling rejects off-screen chunks before draw calls, significantly improving frame rate when view distance contains many chunks.

Output: Renderer calculates frustum planes from camera matrices, tests each chunk's bounding box, and only draws visible chunks.
</objective>
