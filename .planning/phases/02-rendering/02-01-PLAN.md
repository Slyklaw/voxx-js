  <name>Task 1: Add WebGL 2.0 context creation with fallback</name>
  <files>src/core/engine.js</files>
  <action>
    Modify initWebGL() to attempt WebGL 2.0 first, fall back to WebGL 1.0:

    1. Try: this.gl = this.canvas.getContext('webgl2')
    2. If null, try: this.gl = this.canvas.getContext('webgl')
    3. If still null, try: this.gl = this.canvas.getContext('experimental-webgl')
    4. Store detected version: this.glVersion = this.gl instanceof WebGL2RenderingContext ? 2 : 1
    5. Log which version was obtained: logger.info(`WebGL ${this.glVersion}.0 context obtained`)
    6. Throw error only if all three fail

    Keep existing error handling pattern. Do NOT modify renderer.js in this task.
  </action>
  <verify>grep -n "webgl2\|webgl\|experimental-webgl" src/core/engine.js | head -10</verify>
  <done>Engine attempts webgl2 first, falls back to webgl, stores version, logs result</done>

  <files>src/core/renderer.js</files>
  <action>
    Make shaders compatible with both WebGL 1.0 and WebGL 2.0:

    1. Add this.glVersion detection in constructor (use gl.getParameter(gl.VERSION) to parse)

       - WebGL 1.0: no prefix (GLSL ES 1.0)

    5. Keep precision declaration in both versions
