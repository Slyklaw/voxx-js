<task type="auto">
  <name>Task 1: Implement placeBlock() function</name>
  <files>voxx-js/main.js</files>
  <action>
    Implement placeBlock() that:
    1. Calls raycastBlock() to get targeted block
    2. Returns early if hit is false
    3. Calculates placement position by stepping back along ray:
       - Use hit.distance - 0.2 as placeDistance (step back slightly from hit)
       - Calculate world position: start + direction * placeDistance
    4. Converts world position to chunk/local coordinates:
       - chunkX = Math.floor(x / CHUNK_WIDTH)
       - localX = Math.floor(x - chunkX * CHUNK_WIDTH)
    5. Validates bounds (0 <= localY < CHUNK_HEIGHT, etc.)
    6. Gets chunk from world.chunks
    7. Only places if target position is air (chunk.getVoxel() === 0)
    8. Calls chunk.setVoxel(localX, localY, localZ, selectedBlockType)
    9. Calls chunk.updateMesh(true) for immediate update
    
    The -0.2 offset places block in the air cell adjacent to the hit face.
  </action>
  <verify>
    <automated>grep -A30 "function placeBlock" voxx-js/main.js</automated>
    <manual>Right-click on block face - new block should appear adjacent to it</manual>
  </verify>
  <done>placeBlock() places selected block type on adjacent face of targeted block</done>
</task>
