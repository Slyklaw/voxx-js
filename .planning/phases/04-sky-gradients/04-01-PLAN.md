  <name>Task 1: Extend sky shader with multi-stop gradient and dithering</name>
  <files>voxx-js/src/shaders/sky.js, voxx-js/config.js</files>
  <action>
    1. In config.js, add new constants:
       - `export const SKY_STOP_POSITIONS = [0.0, 0.2, 0.5, 0.8, 1.0];` (night, dawn, day, dusk, night)
       - `export const SKY_TOP_COLOR_STOPS = [
           [0.043, 0.063, 0.149],   // night top
           [0.4, 0.3, 0.5],         // dawn top (purple)
           [0.53, 0.81, 0.92],      // day top (sky blue)
           [0.3, 0.15, 0.4],        // dusk top (dark purple)
           [0.043, 0.063, 0.149]    // night top again
         ];`
       - Also define `SKY_BOTTOM_COLOR_STOPS` similarly with horizon-specific colors (warmer tones near horizon for dawn/dusk)
    
    2. Modify sky fragment shader:
       - Replace existing uniforms with arrays: `uniform vec3 uColorStops[5];` and `uniform float uStopPositions[5];`
       - Keep existing `uniform float uTimeOfDay;`
       - Add dithering: `float dither = fract(sin(dot(gl_FragCoord.xy, vec2(12.9898, 78.233))) * 43758.5453);`
       - Implement piecewise linear interpolation between stops:
         ```
         float t = uTimeOfDay;
         vec3 color = uColorStops[0];
         for (int i = 0; i < 4; i++) {
           float start = uStopPositions[i];
           float end = uStopPositions[i+1];
           if (t >= start && t <= end) {
             float factor = (t - start) / (end - start);
             color = mix(uColorStops[i], uColorStops[i+1], factor);
             break;
           }
         }
         ```
       - Apply dithering: `color += (dither - 0.5) * 0.02;`
       - Keep vertical gradient using vPosition.y (mix between top and bottom colors). We need separate top/bottom arrays. Simpler: keep existing vertical gradient using two color arrays (top and bottom). Let's keep uniform arrays for top and bottom: `uniform vec3 uTopStops[5]; uniform vec3 uBottomStops[5];`
       - Then compute `topColor = interpolate(uTopStops, t); bottomColor = interpolate(uBottomStops, t);`
       - Finally `vec3 skyColor = mix(bottomColor, topColor, max(0.0, vPosition.y * 0.5 + 0.5));`
    
    3. Update getSkyUniforms to include new uniform locations.
  </action>
  <verify>grep -l "uTopStops" voxx-js/src/shaders/sky.js && grep -l "SKY_TOP_COLOR_STOPS" voxx-js/config.js && grep -l "SKY_BOTTOM_COLOR_STOPS" voxx-js/config.js</verify>
