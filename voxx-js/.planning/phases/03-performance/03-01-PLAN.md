<objective>
Move matrix calculations from JavaScript per-frame to vertex shaders using instanced rendering.

Purpose: Eliminates redundant model matrix calculations by computing final vertex positions in the GPU shader. Currently chunks are pre-transformed in worker with identity model matrix - switching to instance attributes allows GPU to batch transform all chunks.

Output: Modified voxel shader with instance attributes, updated render path using drawElementsInstanced
</objective>
