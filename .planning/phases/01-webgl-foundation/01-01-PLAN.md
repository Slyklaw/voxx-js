  <name>Register buffer and chunk resources with context registry</name>
  <files>voxx-js/src/gl/buffers.js, voxx-js/src/gl/context.js</files>
  <action>
Modify buffers.js to register each created VBO, VAO, IBO, and wireIBO with context.registerContextResources(). The dispose callback should call the appropriate gl.delete* function. The init callback can be null since buffers will be recreated on mesh rebuild.

For chunkManager.js: ensure dispose(gl) is called when chunks are removed from the loaded set. This may require calling chunkManager.dispose() in the main render loop when chunks go out of render distance.

Create a helper in buffers.js that wraps resource creation with registration, following the pattern from 01-RESEARCH.md lines 84-106.
  </action>
  <verify>

grep -n "dispose" voxx-js/src/chunk/chunkManager.js
  </verify>
  <done>
All buffer/VAO/IBO creations call registerContextResources() and chunk disposal is called when chunks are removed
</done>
</task>

<task type="auto">
  <name>Register shader and FBO resources with context registry</name>
  <files>voxx-js/src/gl/shaders.js, voxx-js/src/gl/fbo.js</files>
  <action>
Modify shaders.js createProgram() to register the created program with context.registerContextResources(). The dispose callback should call gl.deleteProgram(). The init callback should store the shader source strings and re-call createProgram on context restore.

Modify fbo.js createGBufferFBO(), createSSAOBuffer(), and createShadowMapFBO() to register their resources. The dispose callback should call the appropriate dispose* functions (disposeGBuffer, disposeSSAOBuffer, disposeShadowMapFBO). The init callback should recreate the FBO by calling the original creation functions again.
  </action>
  <verify>
grep -n "registerContextResources" voxx-js/src/gl/shaders.js
grep -n "registerContextResources" voxx-js/src/gl/fbo.js
  </verify>
  <done>
All shader programs and FBOs are registered with context registry for proper lifecycle management
</done>
</task>
