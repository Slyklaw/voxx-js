  <action>
    Replace O(n) all-chunks scan with O(1) grid iteration:

    1. Add `getVisibleChunks(cameraX, cameraZ, renderDistance)` method
    2. Calculate camera's chunk coordinates: `camChunkX = Math.floor(cameraX / CHUNK_SIZE)`
    3. Iterate only render distance range:
       ```javascript
       for (let x = camChunkX - renderDistance; x <= camChunkX + renderDistance; x++) {
         for (let z = camChunkZ - renderDistance; z <= camChunkZ + renderDistance; z++) {
           const chunk = this.spatialIndex.get(`${x},${z}`);
           if (chunk) yield chunk;
         }
       }
       ```
    4. Return array of visible chunks instead of scanning all chunks

    This replaces world.js:244-260 which currently scans ALL chunks.
